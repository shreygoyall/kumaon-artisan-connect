# Kumaon Artisan Connect

> AI-powered digital marketplace connecting handloom artisans with wholesale buyers

## 🎯 Project Overview

A full-stack web application built for the Kumaon Heritage Weavers Alliance to provide direct market access to traditional artisans through AI-enhanced customer support.

## 🛠️ Tech Stack

- **Frontend:** React.js with Tailwind CSS
- **Backend:** Node.js + Express.js
- **Database:** MongoDB Atlas
- **AI:** Google Gemini API
- **Deployment:** Vercel + Render

## ✨ Key Features

- Product catalog with advanced filtering
- AI-powered customer support chatbot
- Wholesale inquiry system
- Admin dashboard for artisans
- Mobile-responsive design
