## 🚀 How to Run Backend Locally

### Prerequisites

- Node.js v20+ installed
- npm installed

### Backend Setup

1. Navigate to backend folder:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create .env file:
   ```text
   PORT=5000
   ```
4. Start server:

   ```bash
   npm run dev

   http://localhost:5000
   ```
